# G-Files

Android file manager with a Dark Glassy Blue interface.

## Current features
- Browse internal storage and folders
- Filter Images, Videos, Audio and Documents
- Search files and folders
- Rename and delete items
- Dark / light theme
- GitHub Actions debug APK workflow

## Build
Open in Android Studio or trigger the Android APK workflow from the Actions tab.

The app requires Android All files access permission to manage local storage.
